# GitHub Actions Automation
## Automated Testing & Continuous Integration

A fictional support team flags requests for follow-up as soon as they reach 24 hours. A one-character change can delay every request at the deadline. This independent, AI-assisted portfolio demonstration uses the same four tests locally and in a GitHub Actions workflow to make that regression visible before integration.

Run `python -m unittest discover -s tests -v` from the project root. See the [setup guide](docs/setup.md), [workflow guide](docs/ci-workflow.md), [failure diagnosis](docs/failure-diagnosis.md) and [handover](docs/handover.md). Hosted runs and the CI status badge are pending publication.
